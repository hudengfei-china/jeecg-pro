# 前端代码风格分析

## 工具链
Prettier：行宽 150、2 空格缩进、单引号、分号、ES5 尾逗号、script 块整体缩进。ESLint 关闭 `prettier/prettier` 与 `no-explicit-any`，格式靠 `pnpm batch:prettier` 手动维护，存量存在格式漂移。

## 组件与目录
- 业务页面用 `<script lang="ts" name="模块名" setup>`；底层通用组件沿用 `defineComponent`。
- 标准三层结构：`index.vue` + `模块名.data.ts`（列/表单 schema）+ `模块名.api.ts` + `*Modal.vue`/`*Drawer.vue` + `components/`。
- 事件用 `function handleXxx()`，配合中文 JSDoc；模板注释密度高。

## TypeScript
- `any` 普遍，函数参数常不标注；优先用全局类型 `Recordable`、`Nullable`（免 import）。
- 接口统一 `enum Api` + `export const xxx = (params) => defHttp.get(...)`；Props 多用 `Object as PropType<T>`，几乎不用 `withDefaults`/`as const`。

## 命名
Hooks 用 `useXxx`，Store 用 `useXxxStore`（Options 风格，Pinia），自研组件 `J` 前缀，事件 `handleXxx`/`onXxx`，API 成员小驼峰。

## 导入
路径别名首选 `//@/`（少量 `@/`、`/src/` 混用），顺序惯例：vue → ant-design-vue → `/@/` 组件 → hooks → 相对路径。

## 复用模式
- 元组解构：`const [registerTable, { reload }, { rowSelection }] = useListPage(...)`。
- 权限：`v-auth` 指令或 `usePermission()`；HTTP 统一 `defHttp`。

## 注释
中文为主（约 70%），三种模板：函数上方 `/** 中文说明 @param */`、`// 代码逻辑说明: 【单号】…`、`update-begin--author:...` 成对变更标记（742 处）。
